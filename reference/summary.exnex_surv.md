# Summarize posterior draws from an exnex_surv fit

Summarize posterior draws from an exnex_surv fit

## Usage

``` r
# S3 method for class 'exnex_surv'
summary(object, probs = c(0.05, 0.5, 0.95), ...)
```

## Arguments

- object:

  A fitted \`exnex_surv\` object.

- probs:

  Quantiles to report.

- ...:

  Unused.

## Value

A data frame with posterior summaries.
