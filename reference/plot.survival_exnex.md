# Plot survival curves from an exnex_surv fit

Draws the posterior median and credible band of the survival function
for each group. Requires \`ggplot2\`.

## Usage

``` r
# S3 method for class 'survival_exnex'
plot(x, ...)
```

## Arguments

- x:

  An object of class \`survival_exnex\` returned by
  \[survival_curves()\].

- ...:

  Unused.

## Value

Invisibly returns \`x\`.
