# Summarize posterior draws from an pooling_surv fit

Summarize posterior draws from an pooling_surv fit

## Usage

``` r
# S3 method for class 'pooling_surv'
summary(object, probs = c(0.05, 0.5, 0.95), ...)
```

## Arguments

- object:

  A fitted \`pooling_surv\` object.

- probs:

  Quantiles to report.

- ...:

  Unused.

## Value

A data frame with posterior summaries.
